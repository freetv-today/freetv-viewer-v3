# FreeTV Viewer: Deprecated Code Archive

FreeTV Viewer is a browser-based interface for exploring and watching FreeTV’s hand-picked collection of shows and movies hosted by the Internet Archive. This repository contains the code from versions 1.0.0-beta to 3.0.1-beta.

Check the [Releases](https://github.com/freetv-today/freetv-viewer-v3/releases) if you want to download old versions of the code.

The latest version can be found at: https://github.com/freetv-today/freetv-viewer/

The code in this archive is considered deprecated and is no longer supported.

It is saved here for historical purposes.

### Latest version

You can always find the latest version of the viewer online at: https://freetv.today
